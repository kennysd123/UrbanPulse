![Diagrama del enfoque arquitectónico de UrbanPulse](<../diagramas/enfoque-arquitectonico.png>)

UrbanPulse aplica **Clean Architecture dentro de un monolito modular**. Sus cuatro capas separan presentación, coordinación de casos de uso, reglas del dominio e infraestructura. El dominio define puertos para repositorios y servicios; la infraestructura los implementa y conecta la base de datos relacional y los servicios externos de mapas, WhatsApp y pagos simulados. Así, las dependencias se orientan hacia el dominio y las integraciones quedan desacopladas.
